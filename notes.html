Matrix Calculus for Machine Learning — How to derive backpropagation elegantly Jul 2026
  • Areas: Neural Network, Linear Algebra, Calculus
  • Description: I was confused by the chain rule formula for backpropagation presented in the CS229 instructor’s slides. The chain rule was written from right to left, which is quite different from the one I learned in Calculus. Given this confusion, I tried to verify the formula by hand using a very simple 2-layer neural network example. The formula holds, but I noticed that the computation was quite exhausting. I asked the AI Chatbot about the reverse order and the complicated verification process, which led me to the topic of Numerator & Denominator Layout and the Fréchet derivative. Days later, I encountered trouble computing the explicit expression of the gradient in terms of the parameter matrices, especially for the position of the transpose sign. I asked AI again and learned about the concept of matrix differential. I noticed that the matrix differential is closely related to the Riesz Representation Theorem I learned in MAT2042, and that the Fréchet derivative is based on a proof I encountered in a MAT1012 homework assignment. I synthesized the knowledge I gained in Calculus and Linear Algebra, along with some I gained from chatting with AI, to develop this note, which starts with basic, rigorous definitions and culminates in a practically useful method for computing gradients. I hope this note helps beginners in Machine Learning who have taken Calculus and Linear Algebra courses but are unfamiliar with Matrix Calculus.

Hessian and Strict Convexity Jun 2026
  • Areas: Convex Analysis, Calculus
  • Description: This is the first note I’ve written. It is inspired by a question raised by a fellow student in an EE364a lecture. The question was “whether a function could still be strictly convex if its Hessian is zero at some points”. It reminded me of a lemma I encountered in Calculus, which states that “a function with one variable is strictly convex if its second-order derivative is positive except for a finite number of points.” I combined this lemma with the line restriction method I learned in Convex Optimization, and gave a better statement, “a function with multiple variables is strictly convex if its Hessian is positive definite except for a finite number of points. I lacked experience when I wrote this first note, so it may not look that professional (although my other notes are not that professional either).
