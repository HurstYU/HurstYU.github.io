Put your image files here, e.g.:
  assets/track-1.jpg   (album cover for the first song on music.html)
  assets/track-2.jpg   (album cover for the second song on music.html)

Then in music.html, replace each <div class="cover-placeholder">...</div>
with:
  <img class="cover" src="assets/track-1.jpg" alt="Album cover of [Song Title]">

You can delete this file once you've added your own images.
